# Wraith Console

Developer dashboard for the Wraith Protocol platform. Built with React, Vite, TypeScript, and Tailwind CSS.

## Prerequisites

- Node.js 22+
- pnpm

## Install

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Format

```bash
pnpm format        # auto-fix
pnpm format:check  # check only
```
